# InfinitiPilot

InfinitiPilot is a personal, self-hosted assistant application for a single
household. It connects to the owner's own Google and Microsoft accounts to
read mail, calendars, and media on the owner's private devices.

- **Audience:** the application owner only — it is not offered to the public.
- **Hosting:** runs on the owner's own machines; there is no hosted service.
- **Privacy:** see [PRIVACY.md](PRIVACY.md).

This repository exists to host the application's home page and privacy
policy for its OAuth consent screen.
